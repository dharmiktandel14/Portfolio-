# PORTFOLIO — Tandel Dharmik

React + Vite + Tailwind CSS + Framer Motion + Matter.js + React Router.

## Run
```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in /dist
```

## Customize
- `src/config.js` → name, email, location, GitHub / LinkedIn / Instagram links
- `src/components/Projects.jsx` → fill in your 3 projects
- `src/components/About.jsx` → replace the "TD" box with your portrait image
- `src/components/Contact.jsx` → connect the form to EmailJS / Formspree / your API
